# lite 产品路线图

学员面，任务系统。课程与实训都是任务序列，首屏任务卡，无选择、无导航、无配置——学员在做，不在看，不建播放器。形态为 Web（不发小程序），与 site 同构部署；首切片已落地，部署 `lite/*` tag → `lite.class.quanttide.com`。

## 待办

### v0.1 剩余

- [ ] 登录：复用 studio 已接的 qtcloud-auth
- [ ] 提交通道：修订与交付回传，依赖 provider v0.2 契约

### v0.2 任务系统成型

- [ ] 任务列表：有序、过门槛（完成上一任务解锁下一任务）
- [ ] 任务状态机：待做 / 进行 / 已交 / 退回 / 通过，首屏永远只突出当前任务
- [ ] 题面嵌媒体：任务详情可嵌播放件（内嵌，不是播放器）
- [ ] AI 即时判定：学员自由作答由 AI 判定给反馈，教师异步批改兜底——"判定和反馈当场给"靠这层兑现
- [ ] 数据归置：经 provider 通道，每任务挂一条 criterion 回写完成记录

明确不做：选课、课表浏览、课程目录、任何配置项；不让学员选择"做什么"——被动指派，主动判断（任务内的选择属任务动作，不属导航自由度）。
