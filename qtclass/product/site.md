# site 产品路线图

站点是招生门面，只做门外的事：课程体系展示与价格（询价）。登录后功能一律不进——学员的进 lite，教师的进 studio。无首页，`/` 直达课程。

## 已定口径

- 课程单一列表：不区分理论 / 实践（所有课程都是实践课），训练营不在课程页，详情 `/schedules/:slug` 保留深链可达
- 价格只展示三种服务模式卡（G 端校企合作 / B 端企业 / C 端个人），定价跟对象与商业模式走，不跟课程走，不标价格数字、不展示明细
- 学习页 `/learn` 已下线：任务板块不对外路由，训练营详情独立路由
