# 实训基地路线图（课堂侧）

课堂视角：实训基地在量潮课堂中的角色。公司级全景见 `intro/training-base.md`（双路径枢纽——本文件只讲课堂路径）。

## 课堂路径（路径 A：课堂 → 招聘）

- **免费上课送实习**：课堂学员经实训基地获得实习/招聘机会
- 微专业内容支撑（理论课、实践课、生产实习）
- 生产实习与试用期匹配：完成即实训证明，优秀者提供实习机会

## 课堂侧机制

- 实践课承担实训任务（任务书与考核同构——以实际产出为准）
- 生产实习即课程：一个教程对应一门课程（阶段四收敛目标）
- 每周方法论课/群内指导：CEO 讲最新方法论（技术选型/甲方思维/课题点评）

## 课堂侧阶段目标

1. 微专业内容上架（理论课/实践课/生产实习）
2. 实践课与考核衔接（实训任务标准化）
3. 生产实习难度最高标准（以探索为中心，执行放理论课与实践课）
4. 课程业务规模化（平台与内容迭代后）
