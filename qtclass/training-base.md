# 实训基地路线图

实训基地是课堂规模化的关键支点，也是**串联课堂与招聘的枢纽入口**——两条路径并行，侧重于招聘向课堂逆向导流。

## 双路径入口

- **路径 A（课堂 → 招聘）**：免费上课送实习——课堂学员经实训基地获得实习/招聘机会
- **路径 B（招聘 → 课堂）★侧重**：投递 → 准入问卷 → 实训基地选题制考核 → 通过后转课堂体系（无合适岗位则长期实训/转正式学员）

## 考核机制（以实际成果为核心）

- 选题制：自主发现问题 → 课题申请 → 逐轮点评迭代 → 实际产出验收（固定笔试题已淘汰）
- 训练：群聊沟通即训练环节（不沟通就过不了）；点评（否定+原因）是训练本身
- 激励：记账交易——贡献系统给奖励（代金券/现金）；表现突出者可跳过实训直接参与招聘考核（通过考核 ≠ 一定入职，看岗位/项目）
- 方向：技术选型白盒化（结构显性化，RAG 时机判断）；商务话术库（沟通云子系统）

## 阶段目标

1. **入口上线**：双路径入口 + 准入问卷自动化（HR 零维护）
2. **考核与筛选**：选题制课题申请承担招聘考核；生产实习与试用期匹配（优秀者提供实习机会）
3. **竞争模式**："再造一个量潮"——自组队、自找角色、自竞争；生产实习标准=解决能力范围之外的问题
4. **收敛**：考核与课程融合（生产实习即课程）；平台内容迭代后课程业务规模化
