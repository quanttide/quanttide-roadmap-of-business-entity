# 议事支柱路线图

议事制度是治理思想的核心：君主立宪制下两院三模共存（独立行使、两院流转、创始人直接行使），由事项性质而非层级决定走哪条路。

## 现状

制度素材完整（提案权下放全体、代表审议投票、会前核心小组检查、授权密度驱动），系统侧零实现——制度只活在文档里。洞察沉淀见 `governance-authority`（向下放权，向上揽责：揽责是权力权威的来源）。

## 路线

### 近期：最小闭环

- 议事记录：提案 → 审议 → 表决 → 创始人确认 的完整留痕
- 决策留痕：决议与未决点清单结构化承载，可追溯

### 中期：立法流程状态机

- 两院流转：标准事项（下议院 → 上议院 → 创始人确认）与重大事项（上议院 → 下议院 → 创始人确认）
- 状态承载：draft / evolving / settled，模糊是演进中的合法状态

### 远期：三模共存

- 独立行使与创始人直接行使的模式支持
- 授权密度驱动：章程授权越细，两院覆盖面越大

## 原则

- 揽责不是揽权：责任集中在制度制定者手中，权利跟着责任走
- 议事迁移方案：旧体系无法承载时，现有议题重新进系统过一遍
