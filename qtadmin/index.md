# 量潮管理后台路线图

量潮管理后台（qtadmin）是企业治理思想和制度的平台化——展示的不是功能，是治理方法。与量潮云（生产工具）的功能分开，但保留跨云的治理设计（如评审环节）。视角首先是秘书处的管理视角。

核心出发点是限制创始人的权利：减少随意调动，把框架框出来，用制度和流程逼迫隐性经验显性化，让创始人从日常流程中抽离——摆脱创始人依赖。

## 阶段位置

分化已走完：业务域（qtclass、qtcloud、qtconsult、qtdata、qtrecurit）全部归位各平台仓库，CLI 收敛为五个职能域命令。当前处于连接期起步——补齐三支柱载体与治理可视化。

连接期的第一个交叉点是评审环节：事情分下去后没有明确评审人，职责会默认回流创始人。系统承载「分配工作 + 接受评审结果」，在执行环节中加上评审环节（跨执行云、组织云、人事云）。
