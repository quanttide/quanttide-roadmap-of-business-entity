# 资产支柱路线图

资产管理是第二大脑的基石：内部资产三层建模（原始数据 assets、人类分析 data、总结知识 docs），起步于导出飞书和 GitHub 的数据。

## 现状

CLI 已落地三个命令：archive 日志归档、status 结构合规检查、quality 语义质量评估。connect 从邮件扩展出跨群聊天记录搜索，「从飞书数据开始」的起步路径部分落地。

## 路线

### 近期：三层建模与 workspace

- 按 assets / data / docs 三层组织 CLI 数据目录
- 落地「每一个人一个 workspace」：多用户承载，本地文件操作升级为按人隔离
- 承接「复制即备份，备份即归档，归档即可清理」的资产治理认知

### 中期：组织分析工具

- 从数据建模开始，二次抽取让数据更有效
- 以工作案例为资产提炼起点：CEO 介入管理当作投资行为建立案例，AI 总结记录，反哺手册与工程标准

### 远期：飞书与 GitHub 全面接管

- 飞书数据导出与归档清理，逐步降低旧平台地位
- 替代飞书和企业微信的流程：自研平台复制数据 → 备份即归档 → 清空

## 边界

- 复制不等于验证：备份需要校验可恢复性
- 归档的清理需要治理规则：清理不重要的，保留有资产价值的
